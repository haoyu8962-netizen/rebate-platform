# AGENTS.md（apps/api/src/modules/analytics）

埋点事件模块：把客户端上报的埋点事件落库，本模块是这些表的唯一写者。

## 归属与边界

- 风险级与分工以根目录 AGENTS.md 的分工表为准（由 `ops/risk-map.yaml` 生成）。
- 只写 `app.events` 与 `app.event_dedup`，不读写别的模块的表。
- 调用方是 linking 里的事件接收端点（B1-06zo / CT-13h）；本模块不自己开对外入口。
- 留存清理由 platform/maintenance 负责，本模块不设定时或留存删除任务。
- 注销时怎么处理这些记录待负责人定（C-36，暂按 D10-1489 的默认）；处理入口是 `detachUserEvents`，尚未接线。

## 写入规则

- 幂等以去重表的键为准：同一事件重复投递只落一次，最终靠 PG 唯一约束兜底。
- 去重记录与事件写入在同一事务里完成。
- 身份（用户、设备、app）只取服务端注入的参数，不信任上报内容里的身份字段。
- `server_at` 只读注入的 `Clock`。
- 本模块不做入参校验；校验由调用方按契约完成后再调用。

## 测试

- 规则测试在 `test/spec/analytics/**`，由规则测试作者编写，实现者不改。
- 本模块单元测试不连库。
